# North Star Bakery

A responsive sourdough bakery website inspired by Northern New Mexico.

## Website pages
- Home (`index.html`)
- Menu (`menu.html`)
- Our Story (`story.html`)
- Contact (`contact.html`)

## Design
The site uses a soft Northern New Mexico palette of dusty blue, deep blue, cream, warm brown, and clay. It is mobile-first, uses Flexbox, includes responsive layouts, semantic HTML, accessible image text, a responsive `picture` element, and a complete form.

## Story
North Star Bakery centers on a sourdough starter with roots in Chama, New Mexico that has been kept alive for about 100 years.
