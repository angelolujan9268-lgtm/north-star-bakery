## Before submitting to Sophia
1. Upload ALL files and folders to the root of your public GitHub repository.
2. In GitHub, open Settings > Pages.
3. Under Build and deployment, choose "Deploy from a branch".
4. Choose the `main` branch and `/ (root)`, then Save.
5. Wait for GitHub Pages to publish.
6. Open your GitHub Pages WEBSITE address in a private/incognito browser.
7. Click Home, Products, About, and Contact and confirm all pages and images load.
8. Resize the browser below and above 768px to confirm the layout changes.
9. Submit the GITHUB PAGES WEBSITE URL to Sophia — not just the repository URL.
10. Include a screenshot of the working website in the Touchstone submission if the template/rubric asks for it.

Expected website URL format:
https://YOUR-USERNAME.github.io/north-star-bakery/

Important: The repository URL and the live website URL are different.
